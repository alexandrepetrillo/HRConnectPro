## 🔄 Méthodologie A-B-C Détaillée

### 📖 Phase A : Théorie (30% du temps)

**Objectif** : Comprendre les concepts avant de les voir appliqués

**Support** : Slides Markdown dans `/slides/`
- COURS_ETAPE_01_INITIALISATION.md
- COURS_ETAPE_02_SECURITE_LDAP_JWT.md
- etc.

**Pédagogie** :
- Présentation magistrale
- Questions/réponses
- Schémas d'architecture
- Explication des patterns

**Durée** : 25-40 minutes selon la complexité

---

### 🔍 Phase B : Exploration du Code (40% du temps)

**Objectif** : Voir l'application concrète dans un projet réel

**Support** : Code fonctionnel dans le repository Git

**Activités** :
- Navigation guidée dans l'IDE
- Lecture et analyse du code
- Démonstration en direct (démarrage, tests, API calls)
- Observation des logs, BDD, Kafka, Grafana
- Discussion sur les choix d'architecture

**Pédagogie** :
- Le formateur navigue lentement
- Explique chaque fichier, classe, configuration
- Montre les tests qui passent
- Provoque des erreurs pour montrer le comportement
- Répond aux questions

**Durée** : 30-50 minutes selon la complexité

**Points Clés** :
- Les étudiants OBSERVENT un code qui FONCTIONNE
- Ils comprennent le "pourquoi" de chaque choix technique
- Ils voient les patterns en action, pas juste en théorie

---

### 💻 Phase C : Live Coding (30% du temps)

**Objectif** : Appliquer les connaissances par la pratique guidée

**Support** : Exercice créé from scratch ou enrichissement du code existant

**Déroulement** :
1. **Introduction** (2min) : Expliquer l'objectif
2. **Live coding** (60-70%) : Coder en direct, les étudiants suivent
3. **Tests** (20%) : Exécuter, vérifier le résultat
4. **Discussion** (10%) : Questions, bonnes pratiques

**Pédagogie** :
- Le formateur CODE en PARLANT
- Les étudiants REPRODUISENT en même temps
- Correction immédiate si quelqu'un est bloqué
- Le code est COMMITTÉ dans Git à la fin

**Durée** : 20 minutes à 1 heure selon l'exercice

**Avantages** :
- Apprentissage actif (pas passif)
- Tous avancent au même rythme
- Le formateur montre les bonnes pratiques (raccourcis IDE, etc.)
- Code de référence disponible après
